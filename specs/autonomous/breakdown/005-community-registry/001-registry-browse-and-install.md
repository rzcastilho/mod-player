## Prompt

> Let a user discover a community plugin inside the player, see exactly what it wants to access, and install it with confidence — without any playback interruption.
>
> The plugin bar offers "Browse registry": a searchable list built from a signed, versioned index the app fetches on launch, daily (outside Performance Mode), and on demand. Each entry shows name, author, short description, requested permissions as icons, API version compatibility, category, last update, and install count where the index provides it; the list supports category filters and sorting by recently updated or install count. A detail page adds the long description, screenshots, the permission list with the author's justification for each, budgets above default if declared, a flashing-content flag for visualizers, and the source link. Empty states: the plugin list says "Only bundled plugins installed — browse the registry"; offline, the browser shows the last cached index with a stale-data notice and installs disabled with "Install requires a connection".
>
> The index signature is verified against the project's published key; an index that fails verification is refused and the last good copy kept, with a warning showing its timestamp. Install downloads the package, verifies its digest against the index, validates the manifest, then shows a permission approval sheet: each permission with its plain-language explanation and the author's justification; required permissions are all-or-nothing (denying one cancels the install), optional ones are approved individually. Network permission is always optional, off by default, and scoped to the declared hosts; High-risk permissions (`network`, `audio.process`) carry a distinct warning, and the sheet warns when a plugin asks for both `network` and a read permission that could be correlated. The client never sends user identity or usage to the registry. Installation never interrupts playback.
>
> Acceptance: when a package's digest does not match the index, the install aborts with "package failed verification" and is logged. When the user approves "Chord Chart" with `ui.panel`, `playback.observe`, and `network: chords.example`, the plugin enables and its panel appears. When the user denies the optional network permission at install, the plugin still installs and its network requests return `permission_denied`. When the user installs during playback, audio is unaffected.

## Scope boundary

Does not cover changing permissions after install, the usage log, sideloading, plugin updates, or publishing.
